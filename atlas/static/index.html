    Let Heliopause see your agents.

    Heliopause runs on this machine only, reads what your agents report, and never wakes or drives them.

    1. 1

      Create your lab

      Done with atlas init. You are the owner.

    2. 2

      Connect Claude Code

      One command adds the status hooks. Each chat shows up as an orb.

      python3 -m atlas hooks
    3. 3

      Add a repo

      Heliopause watches its PRs and CI so red builds land in Needs you.

      Add a name under repos in the lab's atlas.json. The value is the agent that owns it.

      GitHub is off until you turn it on: add "github": {"enabled": true} to the same file. It then uses your gh login to read PRs and checks.

    4. 4

      Send a test alert

      See how a Needs-you card looks and how the Mac chime sounds.

      scripts/atlas-alert needs-owner test "Test alert"

    Just looking? Run the demo lab: python3 -m atlas --lab "$(python3 -m atlas demo-path)"
